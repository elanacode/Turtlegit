# LENOVO (Mise à jour BIOS)

Ce guide vous explique comment mettre à jour ou restaurer le BIOS sur un ordinateur de bureau ou PC portable **Lenovo** (Legion, IdeaPad, ThinkPad, LOQ).

{% embed url="https://www.youtube.com/watch?v=AwOax1uWgYc" %}

***

{% hint style="danger" %}
#### Consignes de sécurité Lenovo :
* Ne débranchez jamais l'alimentation électrique de votre machine pendant le processus de mise à jour.
* Sur les PC portables Lenovo, veillez à brancher le chargeur officiel et vérifier que la batterie est à plus de 30%.
* Dans le BIOS Lenovo, si l'option **BIOS Back Flash** existe, activez-la si vous prévoyez de revenir à une version antérieure.
{% endhint %}

***

## Étapes de mise à jour BIOS Lenovo

1. Rendez-vous sur le site [Lenovo Support](https://support.lenovo.com/).
2. Détectez automatiquement votre machine ou entrez votre modèle (ex : *Legion 5 15ACH6H*).
3. Rendez-vous dans **Pilotes et logiciels** ➜ **Mise à jour manuelle** ➜ **BIOS / UEFI**.
4. Téléchargez le fichier d'installation du BIOS (fichier `.exe`).
5. Fermez toutes vos applications ouvertes, puis faites un clic droit sur le fichier ➜ **Exécuter en tant qu'administrateur**.
6. Suivez les instructions à l'écran et acceptez le redémarrage.
7. L'ordinateur redémarre sur un écran Lenovo avec barre de progression : patientez sans toucher au PC jusqu'au redémarrage complet sur Windows.
