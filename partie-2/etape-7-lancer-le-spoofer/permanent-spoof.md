# Permanent Spoof

Cette page vous guide pour effectuer un spoof permanent. Il s’agit de la méthode principale pour modifier définitivement les informations de votre machine (UUID, MAC, etc.).

{% embed url="<https://youtu.be/3WyDbYRUflg>" %}

{% hint style="danger" %}

#### **Attention particulière pour les cartes mères `ASUS`**

Si vous utilisez une carte mère **`ASUS`** avec l’un des chipsets suivants, **vous devez obligatoirement utiliser le mode EFI** pour que le spoof fonctionne correctement :

> `B560, B660, B760, B860, H410, H510, H610, X670, X870, B650, B850, Z590, Z690, Z790`

Le spoof permanent classique ne fonctionnera pas sur ces modèles `ASUS`.
{% endhint %}

## Configurer le spoof

Sélectionne **UEFI** ou **EFI** selon ta carte mère (voir l'avertissement ci-dessus si tu as une carte ASUS). Vérifie que ta carte mère est bien détectée, garde les 3 options activées (**Ethernet spoof**, **Wi-Fi spoof**, **Redémarrage automatique**), puis clique sur **SPOOF**.

## Confirmer la carte mère

Vérifie que le bon fabricant est sélectionné, puis clique sur **Spoof** pour confirmer.

## Vérifier le résultat

Le spoof est terminé quand le journal affiche **Successfully Spoofed**.
