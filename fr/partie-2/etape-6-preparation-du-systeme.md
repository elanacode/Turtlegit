# Étape 6 – Préparation du système

Cette étape inclura toutes les actions à faire juste après avoir installé Windows, avant de passer au spoof.

{% embed url="<https://youtu.be/50f9cH4cmJo>" %}

{% file src="/files/p5mQXFMuCbQE7q5kf5vu" %}

{% stepper %}
{% step %}

## Ouvrir Sécurité Windows

Ouvre le menu **Démarrer**, tape `Sécurité Windows`, puis appuie sur **Entrée**.
{% endstep %}

{% step %}

## Accéder à la protection antivirus

Va dans **Protection contre les virus et menaces**.
{% endstep %}

{% step %}

## Gérer les paramètres

Clique sur **Gérer les paramètres** sous *Paramètres de protection contre les virus et menaces*.
{% endstep %}

{% step %}

## Désactiver les protections

Désactive :

* **Protection en temps réel**
* **Protection dans le cloud**
* **Envoi automatique d'un échantillon**
* **Protection contre les falsifications**
  {% endstep %}
  {% endstepper %}
