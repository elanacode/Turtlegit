# Windows 10

Cette section permet de créer une clé USB Windows 10 officielle, prête à être utilisée pour une réinstallation propre.

{% embed url="https://youtu.be/FMQ3kEiDOKE" %}

{% stepper %}
{% step %}

## Lancer l'outil

Double-clique sur **`MediaCreationTool_22H2.exe`**. Une fenêtre **Microsoft** s'ouvre.

<figure><img src="https://880056835-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FxrhcMZxpTwuFlSlIEuXp%2Fuploads%2FbZVFpNsLp4BAzHzYAPkv%2Fexplorer_Q6xZx3g036.png?alt=media&amp;token=fd33f742-f75b-4e0a-bad5-edfab9f5bb04" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}

## Accepter les termes

Clique sur **Accepter** pour valider le contrat de licence.

<figure><img src="https://880056835-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FxrhcMZxpTwuFlSlIEuXp%2Fuploads%2FJe0RZCK5UKcExMylIulo%2FSetupHost_tN3jR0AZoR.png?alt=media&amp;token=539f3977-4b04-4494-ab81-8f1664358d13" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}

## Choisir le support d'installation

Sélectionne **Créer un support d'installation (clé USB, DVD ou fichier ISO) pour un autre PC**.

Clique sur **Suivant**.

<figure><img src="https://880056835-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FxrhcMZxpTwuFlSlIEuXp%2Fuploads%2F2Dt5MM3EcQP6G8VgqMqP%2FSetupHost_TH4cxKT2ys.png?alt=media&amp;token=11bb5493-86a1-449f-842d-00105c9e9104" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}

## Garder les options par défaut

Laisse les options telles quelles : **français (France), Windows 10**, **x64**.

Clique sur **Suivant**.

<figure><img src="https://880056835-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FxrhcMZxpTwuFlSlIEuXp%2Fuploads%2Fq0kqzXjE7b7njniXkIAl%2Fimage.png?alt=media&amp;token=c9ffe456-6062-46a9-a733-ad24a0201409" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}

## Choisir le type de support

Sélectionne **Disque mémoire flash USB**.

Clique sur **Suivant**.

<figure><img src="https://880056835-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FxrhcMZxpTwuFlSlIEuXp%2Fuploads%2FAuUTrGtX0YaQaddyy6MU%2FSetupHost_M75TWIBKqr.png?alt=media&amp;token=cef49bbf-079f-466b-89d4-0a9b00de9fba" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}

## Sélectionner la clé USB

Choisis ta clé USB dans la liste. Elle doit avoir **au moins 8 Go**.

<figure><img src="https://880056835-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FxrhcMZxpTwuFlSlIEuXp%2Fuploads%2F0Urlzg7l5Ko6pc1hHyye%2FSetupHost_Jsku2Lvj56.png?alt=media&amp;token=224171a1-a8f7-432d-8b37-7aaf1befbecb" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
Toutes les **données** de la **clé** seront **supprimées**. **Sauvegarde-les** avant de continuer si besoin.
{% endhint %}
{% endstep %}

{% step %}

## Lancer la création

Clique sur **Suivant** pour démarrer le téléchargement et la création de la clé.

<figure><img src="https://880056835-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FxrhcMZxpTwuFlSlIEuXp%2Fuploads%2FGhPDY0uL2h9tF9bmJzQK%2FSetupHost_Rk6bK2HvgA.png?alt=media&amp;token=2661d155-b127-4a47-8c64-489d3a98a1c5" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}

## Patienter

Le processus dure environ **10** à **15 minutes**.

<div><figure><img src="https://880056835-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FxrhcMZxpTwuFlSlIEuXp%2Fuploads%2Fn6Wg23i1SUHIGMzYyVnD%2FSetupHost_Nx724CNkjV.png?alt=media&amp;token=11d229e8-d6e1-4548-b81a-263567b02c14" alt=""><figcaption></figcaption></figure> <figure><img src="https://880056835-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FxrhcMZxpTwuFlSlIEuXp%2Fuploads%2Fz8XVnxxokzwnfbbsLiWL%2FSetupHost_D2T5FmWC3Z.png?alt=media&amp;token=3b0c4a49-8b98-40b0-bae6-e4554b8c6ceb" alt=""><figcaption></figcaption></figure></div>

{% hint style="warning" %}
Ne **débranche pas** la clé USB avant la fin.
{% endhint %}

<figure><img src="https://880056835-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FxrhcMZxpTwuFlSlIEuXp%2Fuploads%2FZFqgBjC7qAB6b8j9hwkC%2FSetupHost_ZWgQRyKS4y.png?alt=media&amp;token=148bed06-eab6-4c25-8cc5-0c17039a5d22" alt=""><figcaption></figcaption></figure>

{% hint style="success" %}
Ta **clé USB** est **prête** dès que cet écran s'affiche.
{% endhint %}
